# truesignal-releases

Public artefacts for TrueSignal. This repository holds release artefacts only; the source repository is private and lives at:

> https://github.com/mahmoudahmed3132/TrueSignal-Rewrite

- `main` — this README and `install.sh` (the installer pinned by each CLI release)
- `registry` — signed sensor manifests and `index.json` (the Hub catalogue)
- releases — `cli/v*` assets consumed by `install.sh`, and Hub release notes
